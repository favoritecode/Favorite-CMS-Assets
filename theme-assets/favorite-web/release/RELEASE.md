# Favorite Web Official 1.1.1

Favorite-Web-Official.zip is the installable Favorite CMS theme package. Upload it from **Admin → Themes → Upload Theme** and activate **Favorite Web Official**.

- Single package root: `favorite-web/`
- Package entries: 62
- SHA-256: 89e62e2498edf5ae20890c52863789106c9e900e118c51a84dfca40045c4311f
- Requires Favorite CMS Core 1.0.10 or newer
- Compatible with Favorite Digital 1.0.12 or newer for digital products, memberships, and shared header navigation

## What's Changed in v1.1.1
- Resolved Media Picker modal backdrop occlusion when closed.
- Restored body scroll and keyboard focus to triggering controls on modal dismissal.
- Added global Escape key listener to close modal.
- Ensured tab reset to Media Library upon reopening.
- Prevented event propagation on backdrop and close button clicks.
