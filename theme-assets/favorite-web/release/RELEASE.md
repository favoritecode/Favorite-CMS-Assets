# Favorite Web Official 1.2.0

Favorite-Web-Official.zip is the installable Favorite CMS theme package. Upload it from **Admin → Themes → Upload Theme** and activate **Favorite Web Official**.

- Single package root: `favorite-web/`
- Package entries: 62
- SHA-256: 8e89f4b9b25ef1de5f61b04920d2f2b5859e76249ffca6e34bf1dff8b1773559
- Requires Favorite CMS Universal Core v1.0.18 or newer
- Compatible with Favorite Digital v1.0.12 or newer for digital products, memberships, and shared header navigation

## Release Highlights (v1.2.0)
1. **Fullscreen Customizer Shell Integration**: Operates seamlessly within Core's full-viewport distraction-free Customizer shell (`100vw` x `100vh`).
2. **10-Section Visual Navigator**: Jump-to-edit ✏️ shortcuts and HTML5 drag-and-drop reordering with live synchronization to section sort order.
3. **Copy & Paste Section Settings**: In-memory component clipboard to duplicate section configurations with 1 click.
4. **Undo / Redo History**: Integrated with Core's `FavoriteBuilder.history` API with keyboard shortcuts (`Ctrl+Z`, `Ctrl+Shift+Z`) and input typing guards.
5. **Universal Media Picker Modal**: Full modal lifecycle with body scroll locking, Escape key dismissal, backdrop close, and focus restoration.
6. **Mobile Responsive Drawer**: Off-canvas toggle button for seamless editing on mobile viewports (&le; 768px).
7. **Same-Origin postMessage Bridge**: High-performance live styling with zero HTTP requests and zero DB queries during preview.
