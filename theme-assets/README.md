# Theme Assets

Visual assets, background textures, and design elements for Favorite CMS themes.

## Guidelines

- **What Belongs Here**: Reusable theme artwork, default hero illustrations, decorative patterns, SVG background textures, and theme banner templates.
- **What Does NOT Belong Here**: Theme source code (PHP, CSS, JS), build configs, or packaged theme archives (.zip distributions).
- **Reusability**: Reusable across official and community Favorite CMS themes as common visual components.
- **Naming Convention**: Lowercase with hyphens indicating role or theme context (e.g., `default-hero-illustration.svg`, `subtle-grid-pattern.svg`).
- **Source Preservation**: Keep vector source files (SVG) where possible alongside any rendered raster versions.
