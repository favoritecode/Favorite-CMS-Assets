# Favorite Multimedia Theme Assets

This directory houses the dedicated theme distribution assets and packages for the **Favorite Multimedia Theme System**.

---

## Directory Structure

```
theme-assets/favorite-multimedia/
├── release/              <-- Distribution packages for the Multimedia Theme System
└── README.md
```

## Critical Asset Isolation Rule

- **Plugin releases and core plugin assets**: strictly located under `plugin-assets/favorite-multimedia/release/`.
- **Theme distribution packages and theme assets**: strictly located under `theme-assets/favorite-multimedia/release/`.

Theme assets MUST NEVER be mixed into `plugin-assets/`.
