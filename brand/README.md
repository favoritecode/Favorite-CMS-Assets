# Brand Assets

Brand identity resources and visual guidelines for the Favorite CMS ecosystem.

## Contents

- `logo/`: Official logos in vector (SVG) and raster (PNG) formats, including dark, light, and monochrome variants.
- `favicon/`: Browser favicons, touch icons, and web app icons in standard dimensions.
- `guidelines/`: Brand style guidelines, typography rules, color palette definitions, and spacing standards.

## Guidelines

- **What Belongs Here**: Official brand marks, logotypes, favicons, brand style guides, and color definitions.
- **What Does NOT Belong Here**: Plugin-specific logos (use `plugin-assets/`), application source code, third-party logos, or untracked draft files.
- **Reusability**: All assets here are reusable across the entire Favorite CMS ecosystem (core documentation, web properties, official plugins, and marketing).
- **Naming Convention**: Use lowercase with hyphens and clear variant descriptions (e.g., `favorite-cms-logo-horizontal.svg`, `favorite-cms-mark-dark.svg`).
- **Source Preservation**: Always retain editable vector source files alongside any exported/raster assets. Do not overwrite source assets when creating optimized derivatives.
