# Screenshots

Product screenshots, feature showcases, and interface captures for Favorite CMS.

## Guidelines

- **What Belongs Here**: High-resolution, crisp screenshots of CMS dashboards, setup wizards, key workflows, and showcase views.
- **What Does NOT Belong Here**: Debugging screen captures, untrimmed desktop images, or any screenshot containing sensitive data (passwords, live tokens, confidential customer information, private domains).
- **Reusability**: Reusable across public documentation, GitHub repository READMEs, product presentations, and marketing materials.
- **Naming Convention**: Lowercase with hyphens indicating view and condition (e.g., `dashboard-overview-dark.png`, `post-editor-fullscreen.png`). Avoid vague names such as `screen1.png` or `screenshot-final.png`.
