# Design Resources & Foundation

Visual design standards, tokens, and user interface foundations for Favorite CMS and the ecosystem.

---

## Design Foundation Index

This directory establishes the unified design principles and tokens that govern Favorite CMS and all future ecosystem extensions (Favorite Pay, Favorite Digital, Favorite Shop, Favorite Web):

- [design-tokens.md](file:///e:/Favorite-CMS-Assets/design/design-tokens.md): Compact token set defining brand colors, neutrals, semantic statuses, 4px spacing scale, border radii, shadows, and control heights.
- [typography.md](file:///e:/Favorite-CMS-Assets/design/typography.md): Typeface stacks, heading hierarchies (H1–H6), body copy standards, font weights, line heights, and relative sizing.
- [ui-principles.md](file:///e:/Favorite-CMS-Assets/design/ui-principles.md): Core design philosophy (simple, clean, accessible, lightweight, content-first, low-overhead) and parent-to-ecosystem visual hierarchy.
- [components.md](file:///e:/Favorite-CMS-Assets/design/components.md): Minimal interaction and visual specifications for buttons, inputs, cards, tables, badges, navigation, modals, and states.
- [accessibility.md](file:///e:/Favorite-CMS-Assets/design/accessibility.md): Baseline rules for WCAG AA contrast, full keyboard navigation, focus states, touch targets, and motion preferences.
- [asset-naming.md](file:///e:/Favorite-CMS-Assets/design/asset-naming.md): Kebab-case naming conventions, standard patterns, and concrete examples across logos, icons, screenshots, and plugin graphics.

---

## Guidelines

- **What Belongs Here**: UI/UX design specifications, token documentation, wireframes, vector source art, and layout references.
- **What Does NOT Belong Here**: Frontend application code (HTML, CSS, JS), build tools, npm packages, or runtime framework code.
- **Source Preservation**: Always preserve original vector master files alongside exported raster assets.
