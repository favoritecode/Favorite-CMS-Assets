# Design Resources

Design files, UI wireframes, mockups, and component specifications for Favorite CMS.

## Guidelines

- **What Belongs Here**: UI/UX design mockups, wireframes, design system tokens/specs, layout mockups, and exported design graphics.
- **What Does NOT Belong Here**: Frontend HTML/CSS/JS source code, framework templates, node modules, or build configurations.
- **Reusability**: Reusable design reference for designers, developers, and ecosystem contributors building user interfaces.
- **Naming Convention**: Lowercase with hyphens specifying component/view and state (e.g., `admin-navigation-layout.svg`, `content-editor-wireframe.png`).
- **Source Preservation**: Keep editable source designs intact alongside any static image exports. Never overwrite raw source assets merely to output web-ready images.
