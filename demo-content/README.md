# Demo Content

Sample media and placeholder content for theme testing, sandbox installations, and onboarding demos.

## Guidelines

- **What Belongs Here**: Royalty-free placeholder images, sample avatar graphics, illustrative demo banners, and dummy media files.
- **What Does NOT Belong Here**: Real customer data, proprietary assets with restrictive licenses, production database dumps, or sensitive user media.
- **Reusability**: Reusable across local testing environments, starter sites, theme previews, and automated test fixtures.
- **Naming Convention**: Lowercase with hyphens indicating asset category and variant (e.g., `placeholder-avatar-01.jpg`, `demo-hero-banner.jpg`, `sample-article-thumbnail.png`).
