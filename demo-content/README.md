# Demo Content

Royalty-free sample media, placeholder images, and illustrative starter content for theme testing, sandbox installations, and onboarding demos.

---

## 1. Purpose & Scope

This directory contains lightweight, safely licensed placeholder content used to populate fresh Favorite CMS test environments, theme previews, and automated test fixtures.

---

## 2. Permissible & Prohibited Content

### Permissible Content
- Royalty-free placeholder images (avatars, blog thumbnails, hero banners).
- Abstract geometric pattern placeholders.
- Sample product photos with open, permissive licenses (CC0, Unsplash License, or Favorite CMS original artwork).
- Dummy text files or structured sample JSON for content import testing.

### Strictly Prohibited Content
- **Real Customer Data**: No real customer photos, personal contact details, or private uploads.
- **Copyrighted Commercial Imagery**: No trademarked brand products, proprietary stock photos with restrictive licenses, or copyrighted logos.
- **Production Database Dumps**: Never store SQL dumps or real database backups here.

---

## 3. Technical Standards

1. **Web-Optimized**: Compress demo images (WebP or JPG under 350 KB each) to keep the repository fast to clone.
2. **Standard Dimensions**:
   - Avatars: 256×256 or 512×512 square.
   - Article / Blog Thumbnails: 1200×630 (1.91:1 ratio).
   - Hero Banners: 1920×800 or 1600×900.
3. **Naming Convention**: Lowercase kebab-case indicating role and number (e.g. `placeholder-avatar-01.jpg`, `demo-hero-banner.jpg`, `sample-product-thumbnail-01.jpg`).
