# Favorite Digital Assets

Visual assets, badges, and marketing graphics for the Favorite Digital plugin.

## Guidelines

- **What Belongs Here**: Plugin branding, marketplace banners, file type badges, licensing diagrams, and promotional graphics for digital products and downloads.
- **What Does NOT Belong Here**: Downloadable digital products, customer license keys, backend plugin code, or distribution archives.
- **Reusability**: Used in Favorite Digital documentation, marketplace entries, and UI workflows.
- **Naming Convention**: Lowercase with hyphens (e.g., `favorite-digital-icon-128x128.png`, `favorite-digital-banner.png`, `download-badge-vector.svg`).
