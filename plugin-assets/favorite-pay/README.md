# Favorite Pay Assets

Visual branding, payment badges, and promotional assets for the Favorite Pay plugin.

## Guidelines

- **What Belongs Here**: Plugin icons, marketplace banners, payment method badge artwork, checkout flow diagrams, and promotional headers.
- **What Does NOT Belong Here**: Payment gateway credentials, secret keys, API access tokens, live transaction records, or plugin PHP/JS code.
- **Reusability**: Used in Favorite Pay documentation, marketplace listings, and checkout UI integrations.
- **Naming Convention**: Lowercase with hyphens (e.g., `favorite-pay-icon-128x128.png`, `favorite-pay-banner.png`, `gateway-badge-placeholder.svg`).
