# Favorite Shop Assets

Visual assets, marketplace media, and storefront graphics for the Favorite Shop plugin.

## Guidelines

- **What Belongs Here**: Plugin identity icons, directory banners, storefront mock illustrations, shopping cart UI symbols, and promotional graphics.
- **What Does NOT Belong Here**: Product catalog data, customer order info, payment secrets, store backend code, or database exports.
- **Reusability**: Used across Favorite Shop documentation, marketing materials, and store templates.
- **Naming Convention**: Lowercase with hyphens (e.g., `favorite-shop-icon-128x128.png`, `favorite-shop-banner.png`, `cart-badge-artwork.svg`).
