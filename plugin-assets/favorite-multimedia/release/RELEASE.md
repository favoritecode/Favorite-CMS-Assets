# Favorite Multimedia v1.0.9

### Release Notes
- **Color Mode Support**: Canonical support for AUTO, LIGHT, and DARK color modes scoped strictly to multimedia components.
- **Active Theme Architecture**: The active Favorite CMS theme continues to own global header, footer, site navigation, and branding. The plugin renders cleanly within any active theme.
- **Author Dashboard & Profile Stability**: Native PHP string title ('Multimedia') and native array submenus ensure 100% compatibility with Favorite CMS core admin shell.
- **Delete UX**: Preserves exact delete toasts and HTTP 403 JSON responses across unauthorized deletion requests.
