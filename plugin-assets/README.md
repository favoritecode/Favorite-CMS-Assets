# Plugin Assets

Visual assets and marketplace media for official Favorite CMS plugins and extensions.

## Subdirectories

- `favorite-pay/`: Visual assets for the Favorite Pay payment plugin.
- `favorite-digital/`: Visual assets for the Favorite Digital downloads and licensing plugin.
- `favorite-shop/`: Visual assets for the Favorite Shop e-commerce plugin.

## Guidelines

- **What Belongs Here**: Extension icons, directory banners, feature badges, and marketplace promotional graphics.
- **What Does NOT Belong Here**: Plugin source code (PHP, JS), Composer files, runtime dependencies, or compiled plugin zip files.
- **Reusability**: Specific to each respective plugin, but shared across docs, repository headers, and directory listings.
- **Naming Convention**: Lowercase with hyphens indicating asset role and dimension where applicable (e.g., `plugin-icon-256x256.png`, `marketplace-banner-772x250.png`).
