# Internal Assets

Internal project assets, design drafts, concept artwork, and works-in-progress.

## Guidelines

- **What Belongs Here**: Early design explorations, brand draft ideas, internal presentation slides, architecture diagrams, and unfinalized visual materials.
- **What Does NOT Belong Here**: Passwords, server credentials, environment secrets, private customer data, or production database backups.
- **Reusability**: Internal to the project team and ecosystem designers; not intended for public distribution or direct inclusion in open-source distributions until finalized and graduated.
- **Naming Convention**: Lowercase with hyphens and draft/date tags where helpful (e.g., `brand-exploration-v1.ai`, `ecosystem-architecture-diagram.png`).
