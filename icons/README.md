# Icons

Vector icons and UI symbols used across the Favorite CMS ecosystem.

## Guidelines

- **What Belongs Here**: Clean vector icons (SVG), UI glyphs, action symbols, and icon source sheets for Favorite CMS interfaces.
- **What Does NOT Belong Here**: Complete logos (use `brand/logo/`), screenshots, code packages (e.g., npm/composer icon fonts), or unrelated third-party icon packs.
- **Reusability**: Shared and reusable across core themes, admin interfaces, documentation, and plugins.
- **Naming Convention**: Lowercase with hyphens indicating purpose and variant (e.g., `chevron-down.svg`, `dashboard.svg`, `user-circle-outline.svg`). Avoid ambiguous names like `icon1.svg` or `test.svg`.
- **Source Preservation**: Keep pure SVG vectors as source files.
